# MyWash

Responsive Neuaufbau der MyWash-Website mit den zentralen Inhalten der bestehenden Live-Seite: Leistungen, Preise, Foto-Service, Parkhäuser, Sitztrocknung, Bewertungen und Termin-Anfrage.

## Lokal starten

```sh
npm install
npm run dev
```

## Assistent

Der MyWash-Assistent beantwortet häufige Fragen zu Preisen, Paketen, Dauer, Parkhäusern, Sitztrocknung, Fotos und Tierhaarentfernung. Außerdem sammelt er die Angaben für eine unverbindliche Anfrage (Standort, Fahrzeuggröße, Paket, Extras, Wunschtermin und Vorname) und übergibt sie erst nach dem Klick auf den Anfrage-Link an WhatsApp. Der Chat ist ein deterministischer FAQ- und Buchungsassistent, kein generatives KI-Modell; es wird kein API-Schlüssel benötigt.

## Designvorlagen

- **Original** – dunkler Hero, helle Flächen und Limettengrün, orientiert an der aktuellen Website.
- **Atelier** – warme Naturtöne und ruhigere Serifenschriften.
- **Urban** – kantigere Karten, stärkerer Kontrast und leuchtendes Gelbgrün.

Die Parkhaussuche zeigt Demo-Ergebnisse. Echte Terminverfügbarkeit und direkte Formularübermittlung benötigen eine Backend-Integration.

## Vor Veröffentlichung

Die Bildmotive sind externe Unsplash-Platzhalter. Durch freigegebene MyWash-Bilder ersetzen und Impressum/Datenschutz auf echte Unternehmensangaben abstimmen.
